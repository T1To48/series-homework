# series-homework

פונקציות JavaScript לאתר הסדרות SeriesHub: גישה לנתוני JSON, פונקציות של מערכים, עדכונים בלי לשנות את המקור ותיקון באגים.

## הרצת הבדיקה

```bash
node check.js
```

## שאלות

### 1. בפונקציה addEpisode לא מספיק לכתוב `{ ...show }`. אילו אובייקטים ומערכים יצרתם מחדש, ולמה?

יצרתי מחדש את מערך הסדרות, את אובייקט הסדרה, את מערך העונות, את אובייקט העונה ואת מערך הפרקים. `{ ...show }` הוא עותק רדוד, ולכן `seasons` בעותק עדיין מצביע על אותו מערך של המקור. כדי להוסיף פרק בלי לגעת במקור צריך להעתיק כל רמה בדרך אל מערך הפרקים. סדרות ועונות אחרות נשארות אותם אובייקטים, כי לא שינינו אותן.

### 2. בתקלה #3 העמית כן עשה עותק עם `...`. למה זה לא עזר?

העותק נעשה רק אחרי ה־`push`, כלומר אחרי שהמערך המקורי כבר השתנה. בנוסף, העותק רדוד: הוא מעתיק רק את הרמה העליונה של הסדרה, ו־`seasons` בעותק מצביע על אותו מערך בזיכרון. לכן הסדרה ה"חדשה" והמקורית חולקות את אותן עונות ואת אותם פרקים.
